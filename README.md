# portfolio-website

## Overview

This repository contains my personal portfolio website, built to showcase my projects, technical skills, and journey as a software developer and Business Systems student.

The website serves as a central place where recruiters, employers, and collaborators can learn more about me and explore my work.

## Features

* Responsive design
* About Me section
* Projects showcase
* Contact page
* Modern user interface
* Easy navigation

## Technologies Used

* Python
* Flask
* HTML5
* CSS3
* JavaScript
* Git

## Getting Started

### Clone the repository

```bash
git clone https://github.com/YOUR_USERNAME/portfolio-website.git
```

### Install dependencies

```bash
pip install -r requirements.txt
```

### Run the application

```bash
python app.py
```

Open your browser and visit:

```
http://127.0.0.1:5000
```
